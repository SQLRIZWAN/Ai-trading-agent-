# 🤖 AI Trading Agent

An AI-powered crypto & commodity trading agent with **Spot**, **Futures (Long/Short)**, and **Demo (Paper)** trading modes. Signals are generated by **Google Gemini AI** using real-time price data, on-chain metrics, social sentiment, and technical analysis. The dashboard is hosted on **GitHub Pages** and uses **Firebase Firestore** as its real-time database.

## 🚀 Quick Start

### 1. Fork & Clone
```bash
git clone https://github.com/YOUR_USERNAME/Ai-trading-agent-.git
cd Ai-trading-agent-
```

### 2. Set Up Firebase

1. Go to [Firebase Console](https://console.firebase.google.com) → Create project
2. Enable **Firestore Database** (Production mode)
3. Enable **Firebase Authentication** → Google sign-in
4. Go to Project Settings → Service Accounts → **Generate new private key** (download JSON)
5. Deploy Firestore rules:
   ```bash
   npm install -g firebase-tools
   firebase login
   firebase deploy --only firestore:rules,firestore:indexes
   ```
6. Update `dashboard/js/firebase-config.js` with your project's web config

### 3. Configure GitHub Secrets

Go to **Settings → Secrets and variables → Actions** and add:

| Secret | Description |
|--------|-------------|
| `FIREBASE_PROJECT_ID` | Your Firebase project ID |
| `FIREBASE_PRIVATE_KEY` | Service account private key (full PEM) |
| `FIREBASE_CLIENT_EMAIL` | Service account email |
| `GEMINI_API_KEY` | Google AI Studio API key |
| `TELEGRAM_BOT_TOKEN` | BotFather token (optional) |
| `TELEGRAM_CHAT_ID` | Your Telegram chat/group ID (optional) |
| `COINGECKO_API_KEY` | CoinGecko API key (free tier works) |
| `BINANCE_API_KEY` | Binance read-only API key |
| `BINANCE_API_SECRET` | Binance API secret |
| `ALPHA_VANTAGE_API_KEY` | For Gold/Silver prices |
| `ETHERSCAN_API_KEY` | Etherscan API key (free) |
| `BSCSCAN_API_KEY` | BscScan API key (free) |
| `SOLSCAN_API_KEY` | Solscan API key |
| `MORALIS_API_KEY` | Moralis Web3 API key |
| `LUNARCRUSH_API_KEY` | LunarCrush social data |
| `CRYPTOPANIC_API_KEY` | CryptoPanic news feed |
| `SANTIMENT_API_KEY` | Santiment API key |
| `ENCRYPTION_KEY` | Random 32-char string for AES key derivation |

**Also add these GitHub Variables** (Settings → Variables):
| Variable | Default |
|----------|---------|
| `GEMINI_MODEL` | `gemini-2.0-flash` |
| `MIN_SIGNAL_CONFIDENCE` | `75` |
| `MIN_LIVE_CONFIDENCE` | `80` |
| `MIN_DEMO_CONFIDENCE` | `70` |
| `DEMO_INITIAL_BALANCE` | `10000` |

### 4. Enable GitHub Pages

Settings → Pages → Source: **Deploy from branch** → `main` → `/dashboard`

### 5. Enable GitHub Actions

Go to **Actions** tab → Enable workflows. They will start running on schedule automatically.

## 🤖 AI Signal Generation

Signals are generated by **Gemini 2.0 Flash** every 15 minutes per asset using:

- **Price & Volume** — CoinGecko + Binance real-time klines (1h, 4h, 1d)
- **Technical Indicators** — RSI-14, MACD(12,26,9), Bollinger Bands(20,2), EMA 20/50/200
- **On-Chain Data** — ETH gas, whale transactions, Solana stats, BSC activity
- **Sentiment** — LunarCrush Galaxy Score, CryptoPanic news, Santiment dev activity
- **Futures Data** — Funding rate, open interest trend, long/short ratio, taker ratio
- **Global Context** — BTC dominance, total market cap, alt season indicator

### Signal Output (Spot)

{
  "signal": "BUY",
  "confidence": 87,

## 🔐 Security

- **Exchange API keys** are encrypted with AES-256-GCM client-side using WebCrypto before being stored in Firestore. The raw key never leaves your browser.
- **Firestore rules** ensure users can only read/write their own data.
- **GitHub Actions** service account has minimal permissions (Firestore read/write only).
- **Telegram alerts** never include sensitive account information.
